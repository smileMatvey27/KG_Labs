# 🌋 Vulkan Starter App — Лабораторная работа №1

**Вариант 5: Правильная сфера (~100 вершин).**

Требуется построить сферу, аппроксимированную примерно 100 вершинами, и корректно отрисовать её с учётом матриц проекции и аффинных преобразований.

**Реализация в проекте:**
- Сфера генерируется через UV-параметризацию (`theta × phi`) в файле `source/sphere.cpp`.
- Разбиение: `9 × 9` → `(9+1) × (9+1) = 100` вершин.
- Индексов: `9 × 9 × 6 = 486` (по 2 треугольника на ячейку).
- Цвет вершины вычисляется процедурно по её нормали: `color = normal * 0.5 + 0.5`.

## Сборка

### Windows
1.  **x64 Native Tools Command Prompt for VS 2022**

2. Сконфигурировать проект:

   ```cmd
   cmake --preset debug
   ```

4. Сборка:

   ```cmd
   cmake --build build-debug --parallel
   ```
   При первой сборке CMake скачает зависимости (glfw, imgui, glm, vk-bootstrap, VMA) и скомпилирует шейдеры (`shaders/*.vert` → `*.spv`). Это может занять несколько минут.

5. Запуск проекта:
    ```cmd
   build-debug\vulkan-starter-app.exe
   ```
